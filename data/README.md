# Local video data

Competition videos and third-party datasets are intentionally not distributed
in this public tree. Put local test videos in this directory if convenient;
everything except this README is ignored by Git.

The command-line interface also accepts videos from any path:

```bash
goodlab-fatigue /path/to/driver-video.mp4
```

Before publishing sample data, verify consent, privacy, portrait rights, and the
original dataset's redistribution terms.
