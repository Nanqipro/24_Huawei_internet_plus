# Model artifact

`fatigue-detection-v4-c7-320.onnx` is the 320×320 ONNX artifact retained from
the GOODLAB competition archive.

- SHA-256: `f83a6471cbd928ce66bb51fa9f9011d6abf0a92174bcf1e8dcd97d1ca4e89498`
- size: approximately 24 MB
- detected cues: face, phone, open/closed eyes, yawn/closed mouth, and
  head-orientation classes used by the temporal pipeline

The training dataset is not included. Before making the repository public, the
rights holder should confirm that the model weights and every training dataset
permit redistribution. A future source-code license does not automatically
license third-party data or model artifacts.
